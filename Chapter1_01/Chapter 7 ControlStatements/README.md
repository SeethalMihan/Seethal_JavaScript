# Chapter 7: Control Statements

These beginner JavaScript exercises use `if`, `else if`, `else`, and logical
operators to make decisions based on values.

## Exercises

| File | Exercise |
|---|---|
| `Task1.js` | Check whether a number is even or odd |
| `Task2,js` | Categorize an HTTP status code |
| `Task3.js` | Compare expected and actual test results |
| `Task4_Statuscode.js` | Classify a bug's severity from its impact score |
| `Task5_Testcasepass.js` | Check whether a year is a leap year |
| `Task6_BugSeverity.js` | Assign a grade based on marks |
| `Task7_Health reporter.js` | Report build health from the test pass percentage |
| `Task8_LoginLockout.js` | Display login status and remaining attempts |

## Run an exercise

Install Node.js, open a terminal in this folder, and run a file. For example:

```bash
node Task8_LoginLockout.js
```

Each file contains its own sample input. Change the values near the top of a
file to try different outcomes.
