# Chapter 1: JavaScript Basics

Beginner-friendly JavaScript examples covering values, operators, comparisons,
and variables.

## Examples

| Topic | Files |
|---|---|
| Basic output, addition, and odd/even checks | `01_Basics.js`, `02_Basic.js`, `03_Sum.js`, `04_OddEven.js` |
| Arithmetic and compound assignment | `ArithmaticOperator.js`, `compoundoperator.js` |
| Increment and nullish coalescing | `IncreamentOperator.js`, `nullishoperator.js` |
| Comparisons and equality | `Comparisonoperator.js`, `StrictComparison.js`, `Loosestrict.JS` |
| Logical and conditional operators | `Logicaloperator.js`, `Logical Operator`, `Ternary operator.js` |
| String concatenation | `String Concatenation Operator.js` |
| Variables and scope | `Var_Let_Const.js`, `Var_Example.js`, `Var and FunctionScope.js`, `Let and Block Scope.js` |

Additional examples are organized in [Literals](../Literals/) and
[Var_Let_Const](../Var_Let_Const/).

For a deeper explanation of variable declarations and scope, see
[JavaScript Variables and Scope](./JavaScript_Variables_and_Scope.md).

## Run an example

Install Node.js, open a terminal in this folder, and run a file:

```bash
node 04_OddEven.js
```
