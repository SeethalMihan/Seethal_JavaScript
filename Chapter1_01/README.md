# Chapter 1: JavaScript Basics

Beginner JavaScript examples:

- `01_Basics.js` prints a greeting and a variable.
- `02_Basic.js` prints a greeting and the number 10.
- `03_Sum.js` adds two numbers.
- `04_OddEven.js` checks whether a number is odd or even.

Run an example with Node.js from this folder:

```bash
node 04_OddEven.js
```
