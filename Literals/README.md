# JavaScript Literals

This folder contains beginner examples of JavaScript values written directly
in code, also known as literals.

## Examples

| File | What it demonstrates |
|---|---|
| [Literal.Js](./Literal.Js) | Number, string, and boolean values assigned to variables |
| [Literal_Number.js](./Literal_Number.js) | Positive, negative, decimal, and zero number values |
| [nullVsUndefined.JS](./nullVsUndefined.JS) | An uninitialized variable (`undefined`) and an explicitly empty value (`null`) |

For example, `25` is a number literal, `"John"` is a string literal, and
`true` is a boolean literal. JavaScript also has `null` to represent an
intentionally empty value. A declared variable without an assigned value is
`undefined`.

## Run an example

From this folder, run a file with Node.js:

```bash
node Literal_Number.js
```
